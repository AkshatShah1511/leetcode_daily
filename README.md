# LeetCode Daily — Python

One repository for daily LeetCode practice solutions. All solutions are Python 3, with filenames based on the LeetCode question number, such as `0001_two_sum.py`.

Each solution includes approach comments, correctness reasoning, and time/space complexity, and uses the LeetCode-compatible interface. Examples and relevant edge cases are checked before upload; local tests do not imply an accepted LeetCode submission.

## Daily additions

A ChatGPT scheduled task is enabled for around 8 AM Asia/Calcutta (IST), starting October 1, 2026. It adds one new solution per local day to this repository. Execution depends on the task service and GitHub access remaining available.

Problem selection prefers the verified official daily challenge. If unavailable or already present, an unsolved public algorithm problem is selected and labeled as a fallback. Existing solutions are preserved, and duplicate additions are avoided. No additional repositories are created.
